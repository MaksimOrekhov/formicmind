# FOR-37 — качество imitation MLP

## Вывод

**NO-GO: не переходить к самостоятельному обучению по этому результату.** MLP приблизила teacher logits, но ни разу не совпала с полным `ActionV2` на train, validation или held-out. В held-out точность полного действия — **0%** как у обученной, так и у необученной сети. Матчевые результаты также не показывают конкурентного поведения: модель проиграла `balanced:v2` и `rush:v2`, а против `turtle:v2` дожила до timeout с нулём еды.

Часть логитов и отдельных полей действия обучилась, а выходы оставались легальными через общий decoder. При этом набор после дедупликации мал для переноса: все пять held-out map/opponent групп ниже установленного минимума 100 решений. Поэтому этот эксперимент не даёт основания запускать PPO, self-play или иной самостоятельный обучающий цикл.

Следовательно, MSE к непрерывным логитам в текущей постановке пока не научила модель решениям учителя в смысле фактически применяемого действия.

## Инференс

RTX 5080, PyTorch `2.15.0+cu134`, CUDA runtime `13.4`, Python `3.12.10`. Runtime smoke дал конечный выход `(2, 17)`. На 512 held-out вызовах end-to-end latency составила mean **0.389 ms**, p50 **0.393 ms**, p95 **0.442 ms**, throughput около **2,569 решений/сек**. Эти значения относятся к выбранному локальному GPU runtime.

## Пороговое решение и следующий шаг

| Заранее объявленная проверка | Результат |
| --- | --- |
| Held-out ≥200 решений, ≥4 trajectory groups и ≥100 решений в каждом контексте | **FAIL:** 221 решения и 12 групп суммарно, но все 5 контекстов имеют 11–99 решений |
| Held-out full-action accuracy ≥80% | **FAIL:** 0% |
| Прирост над untrained ≥20 процентных пунктов | **FAIL:** 0 п.п. |
| Logit MSE ниже untrained | PASS: 0.7933 против 2.6305 |
| Легальность 100% и checkpoint загружается | PASS |
| Validation→held-out gap ≤15 п.п. | PASS: 0 п.п., но обе exact accuracy равны нулю |
| Dataset/checkpoint provenance и split checks | PASS |

Суммарный результат — **NO-GO / недостаточно доказательств**. Перейти к самостоятельному обучению пока не стоит. Следующий полезный эксперимент — сначала увеличить эффективное число независимых решений и добиться полноценной validation по каждому контексту; отдельно заранее зарегистрировать сравнение objective, которое проверяет точное декодированное действие, сохранив logit-MSE baseline. Затем повторить held-out и реальные матчи. Не использовать текущий held-out для выбора параметров. Этот отчёт не обосновывает и не реализует PPO или self-play.
